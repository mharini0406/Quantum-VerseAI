# ⚛️ QuantumVerse AI

**Learn Quantum Computing the Interactive Way**

QuantumVerse AI is an interactive educational platform designed to help students learn quantum computing through lessons, simulations, quizzes, and AI-assisted guidance.

---

## 📖 Project Overview

QuantumVerse AI simplifies complex quantum computing concepts by combining:

- Interactive lessons
- Quantum circuit simulations
- AI-powered tutoring
- Practice quizzes
- Student progress tracking

The project is built using Flask, HTML, CSS, JavaScript, and Qiskit.

---

## ✨ Features

### 📘 Interactive Learning

- Beginner-friendly lessons
- Step-by-step explanations
- Code examples
- Real-world applications

### ⚛️ Quantum Lab

- Build simple quantum circuits
- Experiment with quantum gates
- Understand circuit behavior

### 🖥 Quantum Simulator

- Simulate quantum circuits using Qiskit
- Display measurement results

### 📝 Practice Quiz

- Multiple-choice questions
- Instant feedback
- Score tracking

### 🤖 AI Tutor

- Ask quantum computing questions
- Receive simple explanations
- View sample Qiskit code

### 📊 Dashboard

- Learning progress
- Quiz performance
- Achievements
- Course completion

## 🚀 Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
